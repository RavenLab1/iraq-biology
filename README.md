# أحياء السادس العلمي العراقي

موقع عربي يضم مخططات دراسة الفصول الخمسة ولوحة دراسة قابلة للتحريك والتكبير، واختبارات بحسب فصل واحد أو مجموعة فصول أو المنهج كله.

## التشغيل
افتح index.html في المتصفح. جميع ملفات الموقع ثابتة ولا تحتاج إلى تثبيت مكتبات أو خطوة بناء.

## النشر على GitHub Pages
ارفع محتويات هذا المجلد إلى جذر المستودع، ثم من Settings → Pages اختر Deploy from a branch، والفرع main والمجلد / (root).

## المحتوى
النصوص العلمية والإجابات مستمدة من نسخة الكتاب التي قدمها صاحب المشروع. الأسئلة التدريبية مصاغة من محتوى الكتاب، وليست نسخًا من أسئلة وزارية سابقة. يتضمن الموقع تحليل أنماط أوراق متاحة للأعوام 2016–2025 مع روابط المصادر وحدود التغطية.
